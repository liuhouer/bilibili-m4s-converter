# B站缓存视频处理工具

将哔哩哔哩（B站）客户端下载的缓存文件转换为通用视频格式，并生成可加载的弹幕字幕。

## 功能

- **m4s 合并为 MP4**：自动将分离的 `audio.m4s` + `video.m4s` 合并为单个 MP4 文件（无损复制，不重新编码）
- **弹幕转 ASS 字幕**：将 `danmaku.xml` 转换为播放器可加载的 ASS 字幕文件，支持滚动弹幕、顶部/底部固定弹幕及原色显示

## 目录结构要求

脚本基于 B 站客户端的缓存目录结构编写，需要以下文件：

```
.
├── 120/                    # 画质目录（如 120=4K, 80=1080P）
│   ├── audio.m4s           # 音频流
│   ├── video.m4s           # 视频流
│   └── index.json
├── danmaku.xml             # 弹幕数据（可选，用于生成字幕）
├── entry.json              # 视频信息（标题、分辨率等）
└── cover.jpg               # 封面（可选）
```

## 环境要求

- Windows 7 或更高版本
- PowerShell 3.0+
- 无需手动安装 ffmpeg，脚本会自动下载

## 使用步骤

### 1. 合并音视频

将 `convert.ps1` 放到与 `entry.json` 同级的目录下，运行：

```powershell
# 在 PowerShell 中执行
.\convert.ps1
```

输出：`[视频标题].mp4`

脚本会自动检测 `ffmpeg`，若未安装则从官方源下载到当前目录。

### 2. 转换弹幕为字幕（可选）

将 `danmaku2ass.ps1` 放到与 `danmaku.xml` 同级的目录下，运行：

```powershell
# 在 PowerShell 中执行
.\danmaku2ass.ps1
```

输出：`[视频标题].ass`

### 3. 播放时加载弹幕

- **手动加载**：用 VLC / PotPlayer / MPV 播放 MP4 时，将 `.ass` 文件拖入播放器窗口
- **自动加载**：将 `.ass` 文件改名为与 `.mp4` 同名（如 `功夫.ass` + `功夫.mp4`），PotPlayer 和 MPV 会自动识别加载

## 脚本说明

| 脚本 | 输入 | 输出 | 说明 |
|------|------|------|------|
| `convert.ps1` | `120/audio.m4s` + `120/video.m4s` | `[标题].mp4` | `-c copy` 无损合并，不损失画质 |
| `danmaku2ass.ps1` | `danmaku.xml` + `entry.json` | `[标题].ass` | 支持滚动/顶部/底部弹幕，保留原色 |

## 注意事项

- 两个脚本需要放在 **与 `entry.json` 同级** 的目录中运行
- 自动下载的 `ffmpeg.exe` 会保存在当前目录，下次运行可直接复用
- 弹幕字幕的分辨率会自动读取 `entry.json` 中的视频尺寸进行适配
- 若 `entry.json` 中无分辨率信息，默认使用 1920×1080

## 原理简介

- **m4s 合并**：B 站下载的 `.m4s` 文件为 fMP4 格式，ffmpeg 可直接读取并复用流封装为 MP4
- **弹幕转换**：解析 `danmaku.xml` 中每条弹幕的时间、模式、颜色、字号，映射为 ASS 字幕的 `\move`（滚动）、`\an8`（顶部）、`\an2`（底部）标签，并通过轨道分配算法避免弹幕重叠
